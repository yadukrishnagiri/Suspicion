# Imposter — Motion System v2

## Motion Goal
Create:
- secrecy
- anticipation
- tension
- relief

Avoid:
- slot-machine effects
- spinning cards
- excessive particles
- generic game animations

## Motion Personality
Every animation should feel:
cinematic
intentional
premium
social

## Secret Reveal Sequence (Signature Animation)

1. Tap Reveal
2. Background softly darkens
3. Ambient blur grows
4. Tiny center light pulse
5. Word emerges character-by-character
6. Subtle breathing glow behind content

Duration:
700-900ms

This is the most important animation in the product.

## Discussion Starter Reveal

Stage 1:
Player board fades back

Stage 2:
Spotlight expands from center

Stage 3:
Starter name rises upward

Stage 4:
Small haptic moment

Stage 5:
START THE DISCUSSION

Duration:
900ms

Feels like announcing a contestant.

## Elimination Reveal

Citizen:
Pause → reveal → calm blue wave

Imposter:
Pause → silence → red sweep → IMPOSTER FOUND

The pause creates tension.

## Board State Changes

Eliminated player:
100% opacity → 35%
100% saturation → 0%
Scale 1.0 → 0.97

## New Game Transition

Old game dissolves.
New game fades in from depth.

Feels like entering a new mystery.

## Microinteractions

Buttons:
spring

Tiles:
lift on touch

Selections:
animated border travel

Inputs:
soft focus glow

## Motion Rule

If an animation does not increase suspense,
clarity, or delight, remove it.
