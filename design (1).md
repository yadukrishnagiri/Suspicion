# Imposter — Design System v2

## Product Positioning
Premium social deduction experience.
Not a card game. Not a casino game. Not a generic AI-generated UI.

Keywords:
human, premium, cinematic, social, minimal, confident

## Visual Identity
- Dark-first experience
- Large typography
- Generous spacing
- Focus on people, not cards
- Rounded surfaces (20–28px)
- Strong hierarchy

## Core Screens
1. Home
2. Setup Wizard
3. Private Reveal
4. Discussion Starter
5. Active Player Board
6. Elimination Reveal
7. Result
8. Profile

## Home
Hero statement:
IMPOSTER

Subtitle:
One phone. One group. One liar.

## Setup
Progressive flow:
Players → Imposters → Names → Mode → Category → Start

## Profile
Google Login via Firebase Auth.
Store:
- Google UID
- Display Name
- Recent Player Names

No game history stored.

Auto-suggest previously used player names.

## Reveal Experience
The reveal screen is the hero moment of the app.
Single focus layout.
Player name.
Reveal action.
Secret content.

No clutter.

## Player Board
People-board design.
Not deck-of-cards design.

Active:
high contrast

Eliminated:
grayscale + reduced opacity

## Result
Players Win
Imposters Win

Clear and immediate.
